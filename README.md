# Task Manager App

A production-ready React task manager with local persistence, input
sanitization, error boundaries, and full accessibility support.

## Features
- ✅ Add, complete, and delete tasks
- 💾 Persists to localStorage
- 🛡️ Input sanitization (XSS protection)
- ⚠️ Error boundary + per-field validation
- 📱 Responsive mobile-first design
- ♿ Keyboard navigation & ARIA labels
- 🎯 Filter by all / active / completed

## Getting Started

```bash
npm install
npm start

Open http://localhost:3000.

Production Build
bash
npm run build
npm run serve
